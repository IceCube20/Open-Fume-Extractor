# Contributing

Contributions are welcome when they are based on independently written code and
can be distributed under GPL-3.0-or-later.

1. Describe the hardware and firmware target in the issue or pull request.
2. Keep changes scoped and preserve the non-blocking OFE bus architecture.
3. Add or update tests for routing, protocol parsing and persistence changes.
4. Do not commit device backups, credentials, signing keys, build directories,
   proprietary firmware, vendor DLLs, manuals or logos.
5. State the origin and license of any new library, font, icon or copied asset.

By submitting a contribution, you certify that you have the right to provide it
under GPL-3.0-or-later and that it contains no confidential vendor material.
